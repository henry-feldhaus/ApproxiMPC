# Codex Notes

Lightweight working notes for repo-local context recovery.

Use this directory for:

- session handoff notes
- short changelogs
- next-step checklists
- workflow docs that are useful during active development

Suggested files:

- `CURRENT_CONTEXT.md` for the latest state
- `NEXT_STEPS.md` for queued work
- `CHANGELOG_YYYYMMDD.md` for short dated summaries

These notes are intentionally simple and human-readable.
